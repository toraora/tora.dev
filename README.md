# tora.dev

Personal site of Nathan Wong ([toraora](https://github.com/toraora)), built with [Astro](https://astro.build). Deployed to GitHub Pages on push to `main`.

## Development

Requires Node >= 22.12.

```sh
npm install
npm run dev      # local dev server at localhost:4321
npm run build    # static build to ./dist
```

Blog posts live in `src/content/blog/` as MDX. `/design` is a design exploration playground.
